# Datapack Item IDs

Complete list of all item trigger codes used by the f1sch datapack's item give system.
The client mod sends `/trigger f1sch.give set <code>` and the datapack gives the corresponding item.

**Total:** 1480 regular items + 226 special items (potions, arrows, enchanted books) = 1706 items

---

## How It Works

1. Open the Item Give screen in the client mod (from the Config Screen)
2. Search for and select an item
3. The client sends `/trigger f1sch.give set N` where N is the item's trigger code
4. The datapack's tick function detects the trigger and calls `give_item.mcfunction`
5. The mcfunction matches the code and gives the item via a macro function

This works on **any server** with the datapack installed -- no OP required, no `/give` needed.
